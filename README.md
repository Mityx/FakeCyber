# FakeCyber

## Pantalla de Inicio

Este repositorio incluye una pequeña pantalla de bienvenida que puedes ejecutar
en la terminal. Muestra el logotipo de **FakeCyber** junto con una breve
descripción del proyecto.

Para verla solo tienes que ejecutar:

```bash
python3 start.py
```

## Descripción

FakeCyber es un repositorio de ejemplo utilizado para demostraciones y pruebas
relacionadas con ciberseguridad. El objetivo es contar con un entorno sencillo
que sirva para practicar flujos de trabajo con Git y compartir scripts o
materiales de aprendizaje.

## Archivos incluidos

- `start.py` &mdash; Genera la pantalla de inicio con arte ASCII y colores.
- `README.md` &mdash; Esta guía rápida del repositorio.

¡Esperamos que disfrutes explorando FakeCyber!
